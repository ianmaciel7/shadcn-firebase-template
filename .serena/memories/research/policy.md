# External research memory policy

Before an external information query, first check the relevant project-scoped Serena memory and reuse a current, sufficiently specific finding. Query the external source only when the memory is missing, insufficient, or stale. After the query, store durable and reusable findings with their source, retrieval date, and version/freshness boundary.

Do not store secrets, credentials, personal data, full copyrighted content, or transient/raw responses. The authoritative repository rule is `.agents/rules/rules.md#13-serena-external-research-memory`.
